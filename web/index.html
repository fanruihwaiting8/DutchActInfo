About this page

This page lists weekend activities (Friday, Saturday, Sunday) in the Netherlands for the current month and the next month, so you can see what is on without digging through several agendas.

  • Events outside the Netherlands are filtered out with a city-to-province table covering every Dutch place.
  • The dataset is refreshed automatically every day by a GitHub Actions workflow.
  • Everything is static: no account, no tracking, works offline once loaded.
